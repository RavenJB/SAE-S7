# SAE-S7
Conception et déploiement d’un système d’information

Ce projet utilise les [skills de Matt Pocock](https://github.com/mattpocock/skills). Leur installation est un prérequis pour contribuer au développement.

Les [décisions d’architecture](docs/adr/README.md) suivent le skill [architecture-decision-records](https://github.com/wshobson/agents/blob/main/plugins/documentation-generation/skills/architecture-decision-records/SKILL.md) du plugin `documentation-generation` de la marketplace [`wshobson/agents`](https://github.com/wshobson/agents).

Le [plan de maquette et de test](docs/maquette-et-tests.md) décrit l’environnement commun, les essais locaux et les points à valider avant le développement.
